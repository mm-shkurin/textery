указателя: понять, какой из них ещё описывает реальность, можно было только прочитав
все. Колонка **Статус** отвечает ровно на этот вопрос.

`Актуально` — читать как описание сегодняшнего состояния.

`Закрыт` — план, все шаги которого выполнены.
