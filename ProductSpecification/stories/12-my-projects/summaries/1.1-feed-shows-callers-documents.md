# Scenario 1.1 The feed shows the caller's documents and nothing of anyone else's

## green-usecase (2026-08-03)

**Quirk:** An `error_code` absent from `_ERROR_CODE_STATUS_MAP` silently answers 400 — the map's `.get(code, 400)` default — so 1.1's `UNAUTHENTICATED` refusal would reach the client as 400 where the contract declares 401; `current_owner.py` already answers this same condition with the mapped `UNAUTHORIZED`.
**Where:** `backend/adapters/rest/src/error_handling/exception_handlers.py`, `backend/usecase/src/project/list_projects.py`
**Implication:** Any usecase raising a new `error_code` must land in that map in the same unit, or the status is wrong with every test still green.

## green-usecase (2026-08-03)

**Quirk:** The ADR's "the port refuses `None` owner" invariant exists only as a Protocol docstring and an `AssertionError` in the test fake — neither binds a real implementation, and SQLAlchemy compiles `where(col == None)` to `IS NULL` rather than raising.
**Where:** `backend/usecase/src/project/project_feed_repository.py`, `backend/usecase/tests/fake/project/fake_project_feed_repository.py`
**Implication:** The guarantee holds only where it cannot matter until a conformance test runs every `ProjectFeedRepository` implementation, the real one included.
