  wire-reachable; the real db adapter still no-ops it (`_update_values` asks

  (`application_client.py:128-129`), so the wire shape this scenario exists to enable has
  no end-to-end coverage.

  no Postgres and no live backend in this worktree. It should pass by construction; that
  is reasoning, not a run. Verify when a backend is up.
