# Mockups — story 18 redesign (light theme, 2026-07-28)

Верстка по новому дизайну, присланному заказчиком. Светлая тема — расходится с
существующими тёмными макетами story 1 / story 5. Токены вынесены в `desktop/theme.css`
(общий для всех экранов, чтобы держать каждый файл под лимитом 200 строк).

## Экраны (порядок флоу)

## Расхождения со spec story 18

Макеты вводят то, чего в `18_GenerateThenEdit.md` нет:

1. **Шаг 3–4 (AI-вывод параметров)** — новый backend-вызов до `POST /generations`.
   В 18 после выбора типа генерация стартует сразу.
2. **ИИ-чат правки документа (экран 5)** — в `interview.md` явно вне скоупа
   («Дообработка своего текста через ИИ — будущее, не здесь»).
3. **Загрузка материалов DOCX/PDF/TXT** — не в 18, свой attack surface (парсинг
   недоверенных файлов), нужен отдельный hazard-scan.
4. **Страницы документа** (сайдбар «Страница 1/2/3») — у `Document` story 5 нет
   постраничной модели, только `content`.
5. **«Поделиться»** — публичный доступ к документу, отдельная авторизационная модель.
6. **Голосовой ввод (микрофон в композере)** — не специфицирован.

## Замеченные баги исходного дизайна

- На экране 4 секции 2 и 3 обе подписаны «Параметры генерации». В макете секция 3
  переименована в «Дополнительные материалы».
- Сводка справа на экране 4 говорит «объём — 1000–2000 слов», а селект слева стоит на
  «500-1000 слов» — сводка и форма рассинхронизированы.
- Там же: «на **русский** языке в **академический** стиле» — не согласовано по падежам.
- Экран 5: заголовок документа «История ИИ», но в теле «Данный реферат посвящён теме
  "рефератик"» — плейсхолдер из другого прогона.

## Прогон

(нужен интернет). Ширина макета — 1640px.
