# Сессия 4 — Профиль, личные данные (Desktop + Mobile)

Сначала прочитай `.design/prompts/_common.md` и `.design/cache/MANIFEST.md`.

## Источники
- `.design/cache/nodes/profile-personal.json` — «Профиль - личные данные» (desktop).
- `.design/cache/nodes/profile-mobile.json` — мобильный фрейм рядом; в нём же лежат
  состояния **сохранения** и **удаления** — разобрать их отдельно и перенести оба.

## Область (только эти пути)
- `frontend/src/features/profile/**`
- `frontend/src/shared/components/profile/**`
- тесты в `frontend/src/features/profile/__tests__/**`
- **Навбар и тему не править** — сессия 1.

## Задачи
1. Форма личных данных по desktop-фрейму: поля, лейблы, подписи-ошибки, отступы,
   ширины, порядок.
2. Сохранение: кнопка, её состояния (обычная / disabled / в процессе / успех) и
   куда выводится подтверждение — строго как в макете.
3. Удаление аккаунта: блок, кнопка, диалог подтверждения — состав, тон, порядок
   действий как в макете. Реальное удаление вызывает существующий метод API,
   новый эндпоинт не придумывать; если его нет — отметить в отчёте, UI сделать.
4. Мобильная раскладка по фрейму `Mobile`, брейкпоинт из ширины фрейма.
5. Почта/имя/дата из макета — плейсхолдеры, в код не переносить.

## Отчёт
Правки, состояния кнопок, статус эндпоинта удаления, недостающие ноды (node id),
результат `/test-frontend`.
