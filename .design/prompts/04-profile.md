## Задачи
1. Форма личных данных по desktop-фрейму: поля, лейблы, подписи-ошибки, отступы,
   ширины, порядок.
2. Инлайн-редактирование имени: кнопка «Изменить» раскрывает поле, фокус ставится
   автоматически (autoFocus), без второго клика.
3. Сохранение: кнопка, её состояния (обычная / disabled / в процессе / успех) и
   куда выводится подтверждение — строго как в макете.
4. Удаление аккаунта: блок, кнопка, диалог подтверждения — состав, тон, порядок
   действий как в макете. Реальное удаление вызывает существующий метод API,
   новый эндпоинт не придумывать; если его нет — отметить в отчёте, UI сделать.
5. Мобильная раскладка по фреймам Mobile (360px) для всех четырёх состояний.
6. Почта/имя/дата из макета — плейсхолдеры, в код не переносить.

## Отчёт
Правки, состояния кнопок, статус эндпоинта удаления, недостающие ноды (node id),
результат `/test-frontend`.
