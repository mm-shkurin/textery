# Общая часть (вставляется в каждый промпт сессий 1–4)

- Ветка: `design/figma-alignment`. Работай в **отдельном git worktree**, не в общем
  чекауте (см. `.memory-bank/steerings/development-conventions.md`).
- **Сеть запрещена.** Никаких обращений к `api.figma.com`, никакого `curl`, никакого
  повторного экспорта картинок. Источник истины — `.design/cache/`. Если нужной ноды
  или ассета нет в кэше — остановись и выведи её node id, чтобы сессия 0 добрала
  всё одним батчем. Самостоятельный запрос к Figma = риск 429 и бана токена на 36 часов.
- Читай перед работой: `.claude/guidelines/frontend-rules.md`, `.claude/rules/coding-rules.md`.
- Лимит 200 строк на файл — жёсткий. Разросшийся компонент дели.
- Цвета/шрифты/отступы бери из `.design/cache/tokens.json` и клади в тему
  (`frontend/src/shared/theme`, `frontend/src/styles`). Хардкод hex в компоненте — нет.
- Не выдумывай данные: плейсхолдеры из макета (почты, даты, имена) не переносить
  в код — только реальные пропсы/данные API (см. `/design-review`).
- Правь только свои файлы (список в разделе «Область» твоего промпта). Файлы чужих
  сессий не трогай, даже если там видна ошибка — сообщи о ней в отчёте.
- Тесты: обнови существующие юнит-тесты фронта, что сломались от разметки;
  прогон — `/test-frontend`. Тесты чужих зон не чинить.
- Коммит(ы) в конце: `design(<зона>): <что выровнено>`. PR не открывать.
